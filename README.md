# WebChat
A simple real-time chat application built with React, TypeScript, Node.js, and WebSockets.

## Features
- Real-time messaging using WebSockets
- Room-based chat
- Unique user identity
- Live room user count
- Connection status
- Light and dark mode
- Responsive UI
